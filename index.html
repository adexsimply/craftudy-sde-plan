Two GitHub Actions in every learner repo do the nagging: a 23:30 check that opens a missed-log issue when today's log is absent, and a Sunday digest that counts logs, commits and open PRs. A Sunday summary across all repos lands with the mentor automatically.

The twelve weeks

Each week has one build, a short learn list, a DSA set of three problems, and a done-when line. One primary source per week; an AI assistant for everything else, on the condition that you can explain every line you ship.

  1. Week 1 · 14–20 Sep

    Linux shell and Git, properly

    Build
    A bash script that archives a folder with a timestamp, plus your repo set up from the template with a first PR merged.
    Learn
    Ubuntu (VM, WSL2 or a VPS), core shell commands, SSH keys, branch/commit/PR/merge, why secrets never go in a repo.
    DSA
    Two Sum · Best Time to Buy and Sell Stock · Contains Duplicate
    Done
    The script produces a dated archive; the repo has 7 daily logs and one merged PR.
  2. Week 2 · 21–27 Sep Call Sun 27

    Node without a framework

    Build
    A plain Node HTTP server serving GET /tasks and POST /tasks from a JSON file.
    Learn
    Modules, fs, the event loop, callbacks vs promises vs async/await, process.env, npm scripts.
    DSA
    Valid Anagram · Valid Palindrome · Reverse Words in a String
    Done
    curl can create and list tasks and the data survives a restart.
  3. Week 3 · 28 Sep–4 Oct

    Express and REST

    Build
    Tasks API v1: full CRUD in memory, validation, correct status codes, a central error handler, request logging.
    Learn
    Routing, middleware order, REST conventions, HTTP status codes, validation with zod, Postman or curl.
    DSA
    Group Anagrams · Top K Frequent Elements · Two Sum with a hash map
    Done
    A Postman collection in the repo exercises every route and every error path.
  4. Week 4 · 5–11 Oct Call Sun 11

    PostgreSQL

    Build
    Tasks API v2: users and tasks tables with a foreign key, a migration script, the API reading and writing through pg.
    Learn
    Tables and types, keys, one-to-many, JOIN, indexes, EXPLAIN, migrations, connection pooling.
    DSA
    Valid Parentheses · Min Stack · Queue using Stacks
    Done
    Fresh database + migrate + start = working API. No manual table creation.
  5. Week 5 · 12–18 Oct

    Auth and security

    Build
    Signup and login, JWT-protected routes, each user sees only their own tasks, rate limiting, helmet, .env.example committed.
    Learn
    bcrypt, JWT structure and expiry, Bearer tokens, the top three API vulnerabilities, CORS basics.
    DSA
    Reverse Linked List · Merge Two Sorted Lists · Linked List Cycle
    Done
    User A cannot read, edit or delete User B's tasks, and you can demonstrate it.
  6. Week 6 · 19–25 Oct Call Sun 25 · mid-cycle demo

    Tests and code quality

    Build
    Jest and Supertest covering auth and CRUD, ESLint and Prettier, a README a stranger can follow in two minutes.
    Learn
    Unit vs integration tests, test databases, fixtures, coverage, what a good README contains.
    DSA
    Binary Search · First and Last Position · Search in Rotated Sorted Array
    Done
    Clone, follow the README, green tests.
  7. Week 7 · 26 Oct–1 Nov

    Docker

    Build
    A multi-stage Dockerfile with a non-root user, and a compose file running API and Postgres with a volume, env vars and a health check.
    Learn
    Images vs containers, layers and caching, .dockerignore, volumes, networks, health checks.
    DSA
    Maximum Subarray · Longest Substring Without Repeating Characters · Container With Most Water
    Done
    docker compose up on a clean machine gives a working API, and down then up reproduces it.
  8. Week 8 · 2–8 Nov Call Sun 8

    CI with GitHub Actions

    Build
    Lint and tests on every PR, image build on main, push to GitHub Container Registry, branch protection requiring green checks.
    Learn
    Workflow YAML, triggers, jobs and steps, Postgres as a CI service, secrets, caching, token permissions.
    DSA
    Fibonacci with memoisation · Subsets · Permutations
    Done
    A PR with a failing test cannot merge; a merge to main produces a tagged image.
  9. Week 9 · 9–15 Nov

    Deploy to a real server

    Build
    The API live over HTTPS on a real domain: Ubuntu VPS, firewall, Docker, nginx reverse proxy, TLS via certbot, a persistent database volume.
    Learn
    Provisioning, SSH hardening, nginx, DNS records, Let's Encrypt, database backups.
    DSA
    Maximum Depth of Binary Tree · Invert Binary Tree · Level Order Traversal
    Done
    The health endpoint returns 200 from a phone on mobile data.
  10. Week 10 · 16–22 Nov Call Sun 22

    Continuous deployment and observability

    Build
    Merge to main deploys automatically. Structured logs, a health check that tests the database, an uptime monitor, a documented rollback.
    Learn
    Deploy pipelines, basic zero-downtime restarts, log levels, correlation IDs, what to alert on.
    DSA
    Validate BST · Lowest Common Ancestor · Kth Smallest in a BST
    Done
    Break production on purpose during the call, show the alert, roll back in under five minutes.
  11. Week 11 · 23–29 Nov

    A client on top

    Build
    A small React app with login, task list, create, complete and delete, talking to your API with JWT. Deployed on Vercel or Netlify.
    Learn
    Fetch with auth headers, token storage trade-offs, loading and error states, frontend environment variables.
    DSA
    Number of Islands · Flood Fill · Clone Graph
    Done
    Your mum can use it from her phone.
  12. Week 12 · 30 Nov–6 Dec Call Sun 6 · final demos

    Ship and present

    Build
    Final README with an architecture diagram, a runbook for deploy, rollback and restore, a five-minute demo video, a one-page "what I learned".
    Interview
    30 minutes with Shina: walk through the system, then two DSA problems from the cycle, live.
    DSA
    Re-solve any three earlier problems without looking.
    Done
    You would send the repo link to a hiring manager today.

Rules

  1. Deliverable beats attendance. Nobody is graded on joining a call. You are graded on what is in the repo on Sunday night.
  2. Two missed weekly deliverables and you pause until the next cycle. No chasing, no hard feelings.
  3. Ask early, in writing. Stuck more than 45 minutes: write the blocker in your log. Try an AI assistant first, then a peer, then Shina.
  4. Build, don't watch. Videos and articles are reference. The task is a thing that runs.
  5. One track. Park other ideas in later.md and move on.
  6. Three DSA problems a week, in JavaScript. Approach in plain English before code. Log time per problem.
  7. Commitment week for newcomers. Success and Pamilerin are welcome after a full Week 1: seven logs and the PR.
  8. Everything visible inside the cohort. Repos and logs are open to every learner. Accountability is the point.
